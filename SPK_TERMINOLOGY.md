# 📚 Terminologi SPK (Sistem Penunjang Keputusan)

## 🔤 Istilah yang Benar

### **SPK = Sistem Penunjang Keputusan**

**Bukan:** Sistem Pendukung Keputusan ❌

**Istilah Internasional:**
- **DSS** = Decision Support System
- **CDSS** = Clinical Decision Support System
- **GDSS** = Group Decision Support System

## 📖 Definisi

### **Sistem Penunjang Keputusan (SPK)**

> Sistem berbasis komputer yang membantu pengambil keputusan dalam menyelesaikan masalah semi-terstruktur atau tidak terstruktur dengan menggunakan data dan model.

**Karakteristik SPK:**
1. ✅ Mendukung pengambilan keputusan (bukan menggantikan)
2. ✅ Menggunakan data dan model
3. ✅ Interaktif dan user-friendly
4. ✅ Fleksibel dan adaptif
5. ✅ Berbasis komputer

## 🎯 Komponen SPK

### **1. Database Management System (DBMS)**
- Menyimpan data yang relevan
- Dalam aplikasi ini: Supabase (PostgreSQL)

### **2. Model Management System (MMS)**
- Menyimpan model keputusan
- Dalam aplikasi ini: Metode SAW

### **3. User Interface (UI)**
- Interaksi dengan pengguna
- Dalam aplikasi ini: React + Next.js

### **4. Knowledge Base**
- Aturan dan pengetahuan domain
- Dalam aplikasi ini: Kriteria dan bobot

## 🔢 Metode dalam SPK

### **Multi-Criteria Decision Making (MCDM)**

1. **SAW** - Simple Additive Weighting ✅ (Digunakan)
2. **WP** - Weighted Product
3. **TOPSIS** - Technique for Order Preference by Similarity to Ideal Solution
4. **AHP** - Analytic Hierarchy Process
5. **ELECTRE** - Elimination and Choice Translating Reality
6. **PROMETHEE** - Preference Ranking Organization Method for Enrichment Evaluation


```
Sistem Penunjang Keputusan (SPK) ini dikembangkan untuk membantu 
admin dalam menentukan prioritas order yang harus diproses. 
Metode yang digunakan adalah Simple Additive Weighting (SAW) 
dengan 4 kriteria: Total Pembelian, Waktu Tunggu, Jumlah Item, 
dan Bukti Pembayaran.
```
